# 🛡️ Tajir Network Monitor v4.9.1 [Enterprise SOC Gateway]

Tajir Network Monitor is an advanced, enterprise-grade Python and Tkinter-based Network Security Operations Center (SOC) gateway tool. It monitors live traffic, detects malicious network threats (phishing, malware downloads, tunneling), maps live subnet devices (Wi-Fi vs Wired), and provides automated firewall isolation (`iptables`).

---

## ⚙️ Prerequisites & Requirements

- Linux OS (Kali Linux recommended)
- Python 3.x
- Root privileges (`sudo`)
- Required Python libraries: `scapy`, `requests`
